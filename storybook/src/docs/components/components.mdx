# Components

The smallest, indivisible building blocks of the interface. A component does one thing and one thing only — it cannot be broken down further without losing its meaning. Components have no knowledge of their context or surroundings.

**Use for:** button, link, icon, image, label, tag, badge, input, textarea, select, checkbox, radio, toggle, heading, paragraph, caption, divider, avatar, spinner, tooltip, logo.
