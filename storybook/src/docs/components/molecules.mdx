# Molecules

A combination of two or more atoms that together form a distinct, reusable UI pattern. A molecule has a single, clear purpose. It is still relatively simple and context-agnostic — it does not know where on the page it lives.

**Use for:** form field (label + input + error message), search bar (input + button), navigation item (icon + link), card header (avatar + heading + meta), breadcrumb item (icon + link), pagination control, alert/notification (icon + text + close button), media object (image + text).
