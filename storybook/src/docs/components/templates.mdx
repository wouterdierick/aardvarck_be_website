# Templates

Page-level layouts that arrange organisms into a coherent structure. A template defines the skeleton of a page type — where the header goes, where the content lives, where the sidebar appears — but contains no real content yet. Think of it as a wireframe with real components.

**Use for:** basic page template, article detail template, overview page template, landing page template, search results page template, homepage template.
